Diseño Digital
Sitio web de Diseño Digital, una empresa de Villavicencio, Colombia, especializada en publicidad visual y soluciones para que las marcas destaquen.

El sitio presenta sus servicios, algunos de sus proyectos y distintas formas de solicitar información o una cotización.

Secciones del sitio
Inicio: presentación de la empresa, servicios y formulario para solicitar una cotización.
Portafolio: galería de proyectos publicitarios.
Nosotros: historia, experiencia y compromiso de Diseño Digital.
Contacto: información de contacto, ubicación y formulario de consulta.
Servicios destacados
Letreros comerciales y avisos luminosos.
Señalización corporativa.
Stickers y vinilos.
Pendones y otras soluciones de publicidad visual.
Tecnologías
HTML5
CSS3
JavaScript
EmailJS para el envío de formularios
Google Fonts, Material Symbols y Font Awesome
Ver el sitio localmente
No se requiere un proceso de compilación ni instalar dependencias. Abre index.html en un navegador o ejecuta el proyecto con una extensión como Live Server en Visual Studio Code.

Para probar los formularios, sirve el sitio mediante HTTP; abrirlo directamente como archivo (file://) puede impedir el envío.

Publicación
El proyecto es un sitio estático y puede alojarse en GitHub Pages u otro servicio de hosting estático. Para que los formularios funcionen en producción, revisa en EmailJS la configuración del servicio, la plantilla y los dominios autorizados.
